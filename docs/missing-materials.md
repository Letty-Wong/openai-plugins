# 需要补充的素材清单

## 用途

这份清单用于推进后续 WP-04 之后的视觉原型、产品演示和最终发布验收。当前 WP-03 可以继续使用占位画面；以下素材不会阻塞演示控制壳，但会阻塞正式视觉和最终现场交付。

## P0：正式产品演示前必须补齐

### 产品身份与公开权限

| 项目 | 要求 | 当前状态 |
| --- | --- | --- |
| 唯一花洒产品与型号 | 明确品牌、正式名称、型号/SKU、系列 | 待业务方提供 |
| 公开展示授权 | 确认可在课程演示、截图、会后页面中展示 | 待业务方确认 |
| H1 主视觉角度 | 完整套装三分之四正面角度，后续版本同机位 | 待锁定 |

### 产品主渲染

| ID | 素材 | 规格 |
| --- | --- | --- |
| `PRD-H1-SIL` | 中性产品剪影 | 与 H1 主图同画布、同坐标，透明 PNG 或遮罩 |
| `PRD-H1-WARM` | 暖光主渲染 | 透明背景，主文件高度建议 3600px 以上 |
| `PRD-H1-NEUTRAL` | 中性技术渲染 | 同机位、结构清楚，用于技术解释 |
| `PRD-H1-RED` | 暗色红光渲染 | 与 WARM 像素级注册一致，用于安全转折 |
| `PRD-H1-SHADOW` | 独立接触阴影 | 透明背景，不与产品合并 |
| `PRD-H1-MATTE` | 产品整体遮罩 | 黑白或 alpha matte，用于文字穿越和局部调色 |

硬性要求：`SIL / WARM / NEUTRAL / RED` 画布大小、产品位置、裁切必须完全一致。

### 拆件与局部层

| ID | 候选部件 | 必须独立 |
| --- | --- | --- |
| `PART-01` | 恒温阀体/主体 | 是 |
| `PART-02` | 恒温阀芯 | 是 |
| `PART-03` | 不锈钢升降杆 | 是 |
| `PART-04` | 顶喷 | 是 |
| `PART-05` | 手持花洒 | 建议 |
| `PART-06` | 硅胶出水嘴局部 | 是 |
| `PART-07` | 软管/连接件 | 可选 |
| `PART-08` | 安装底座/进水接口 | 可选 |

交付方式优先：每个零件独立透明图，并保持在 H1 主画布坐标内。

### 产品资料包

每条资料需标记 `VERIFIED / APPROVED / PLACEHOLDER / DO_NOT_USE`，并注明来源/负责人。

- 产品名称与型号。
- 产品规格书。
- 安装说明书。
- 材质说明。
- 功能说明。
- 尺寸图。
- 适用水压与温度范围。
- 认证或测试资料。
- 质保政策。
- 包装资料。
- 公开宣传册。
- 现有产品照片或渲染。

### 业务输出样板

至少补齐 6 类，且必须能追溯到同一份产品资料包：

- 参数到客户利益对照表。
- 朋友圈/社交内容。
- 海报标题与副标题。
- 销售跟进话术。
- 45 秒短视频五段分镜。
- 英文询盘回复初稿。
- 客服 FAQ 或异议处理。

### CTA 与现场信息

- 课程最终标题。
- 讲师、主办方、日期、地点。
- 自测表入口。
- 30 分钟诊断入口。
- 3 天体验课入口。
- 一个主二维码、短链或报名编号。
- 表单隐私说明和数据处理方式。
- 3 天与 3 个月产品的正式交付边界。

## P1：显著提升质感，但不阻塞第一版骨架

- 3-5 秒流水慢动作循环。
- 家庭、酒店、工程安装场景授权图片。
- 360 度产品转台。
- GLB 或 Blender 源文件。
- 去敏后的真实业务界面。
- 工厂、办公、销售、客服等真实影像。

## 文件格式与分辨率

| 类型 | 原始文件 | 网页运行文件 | 建议分辨率 |
| --- | --- | --- | --- |
| 产品渲染 | PNG/TIFF，透明背景，建议 16 bit | WebP，必要时 PNG 回退 | 主文件高 3600-4200px，网页版高 1800-2400px |
| 遮罩 | PNG，灰度或 alpha | PNG/WebP | 与主渲染同画布 |
| 场景图片 | 授权原图 | AVIF + WebP | 至少 2560 x 1440 |
| 视频循环 | ProRes 或高码率 H.264 | MP4 H.264，必要时 WebM | 1080p 或 4K |
| 海报样板 | 设计源文件或高分图 | WebP/PNG | 至少 1600 x 2000 |
| 分镜图 | 图片或设计源文件 | WebP/PNG | 至少 1280 x 720 |

## 建议目录与命名

```text
public/assets/product/shower/
├── renders/
├── parts/
├── scenes/
├── loops/
├── masks/
├── data/
└── source/
```

命名规则：

```text
[对象]_[机位或部件]_[状态]_[版本].[格式]
```

示例：

```text
shower_h1_warm_v01.webp
shower_h1_red_v01.webp
shower_part_cartridge_v01.png
product-facts.json
product-anchors.json
product-claims.json
asset-manifest.json
```

## 明确不要提供或使用

- 随意下载的其他品牌产品图。
- AI 生成的假阀芯或假结构图。
- 假认证、假质保、假价格、假名额。
- 可误扫的随机二维码。
- 未经授权的人物、酒店、客户资料或业务截图。
- 平台 Logo 墙、机器人头像、代码雨、蓝紫霓虹素材包。
