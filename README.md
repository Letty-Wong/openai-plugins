# AI Presentation Web

This repository is being prepared for a 21-scene, presenter-controlled AI
demonstration website.

Current status:

- WP-00 repository audit is complete.
- WP-01 establishes the project contract, stable documentation paths, and a
  minimal Next.js/TypeScript baseline.
- The real presentation, scene data, animations, product assets, QR codes, and
  presenter controller are not implemented yet.

## Commands

```sh
npm run lint
npm run typecheck
npm run test
npm run build
```

## Documentation

- `docs/project-status.md` explains the final goal and current progress.
- `docs/repo-audit.md` records the WP-00 repository audit.
- `docs/scene-spec-master.md` is the authoritative scene and interaction spec.
