# 花洒产品演示：素材与内容准备清单 V1

> 状态：第 09—16 幕前置生产规格。  
> 用途：确定真实产品、视觉资产、业务样板、数据边界与 Scene 08 → 09 连续转场条件；在这些条件锁定前，不进入精细产品动画。  
> 前置文件：`AI演示网页_设计基线_V1.md`、`21幕视觉分镜规格_V1_第二批_05-08.md`、讲师逐字稿。

---

## 1. 本阶段要解决的问题

第 09—16 幕是整套演示网页的视觉与说服力中心。它必须完成一条可见的业务转换：

```text
一个真实产品
→ 一份真实资料
→ 参数被翻译成客户利益
→ 客户利益变成销售与内容素材
→ 同一资料支持多个部门
→ 所有生成结果进入审核和安全边界
```

因此，本阶段不是简单寻找一张花洒图片，而是建立一套可以连续表演的“产品资产系统”。

最终需要让同一个花洒在以下状态间连续变化：

```text
Scene 08：中性剪影
Scene 09：暖光真实产品
Scene 10：技术拆解与资料连接
Scene 11：参数与客户利益转换
Scene 12：销售素材工作台
Scene 13：短视频分镜工作台
Scene 14：外贸、客服与异议处理工作台
Scene 15：多部门复用网络
Scene 16：暗色红光下的安全保护对象
```

核心原则：

> 产品始终是同一个对象。灯光、图层、位置和上下文可以变化，但身份、比例和空间锚点不能跳变。

## 3. 产品视觉策略：首版采用 2.5D，不等待完整 3D

### 3.1 推荐路线

第一版正式演示优先使用：

```text
同一机位的多套透明产品渲染
+ 可独立移动的产品拆件图层
+ 独立阴影与遮罩
+ CSS / GSAP 空间运动
+ SVG 接入环与连接线
```

这一方案可实现：

- 产品穿过巨型文字。
- 暖光与红光环境切换。
- 局部拆解。
- 参数与零件连接。
- 卡片围绕产品重排。
- Scene 08 → 16 的稳定连续性。
- 低配置演示电脑上的可靠播放。

### 3.2 暂不把 GLB 设为阻塞项

真实 3D 模型属于 P1 加分项，而不是 P0 前置条件。

只有在以下条件同时满足时，再将主产品替换为 WebGL：

- 模型结构和比例准确。
- 材质、镀层和玻璃／金属反射经过正式调试。
- 移动端和低性能设备有静态回退。
- Scene 09—16 的二维状态已经稳定。
- 演示电脑经过持续压力测试。

否则，一张高质量、正确打光、同机位对齐的透明渲染，通常比低质量实时 3D 更高级、更可靠。

## 4. 主视觉角度与构图锁定

### 4.1 推荐主机位 H1

产品采用完整套装的三分之四正面角度：

- 花洒立杆保持接近垂直，避免夸张透视。
- 恒温阀体、旋钮或控制区域必须清楚可见。
- 顶喷、手持花洒和升降杆的关系能够一眼读懂。
- 产品略朝屏幕中心，而不是朝画面外侧。
- 镜头建议使用中长焦感，减少立杆和顶喷畸变。
- 金属轮廓需要清晰，但不要烘焙过重背景光。

H1 是 Scene 08—16 的身份基准。后续所有灯光版本必须使用相同相机、相同画布和相同产品坐标。

### 4.2 1920 × 1080 基准构图

```text
ProductStage 中心：x 62% / y 53%
产品整体高度：约 72—80vh
产品最大宽度：约 28—34vw
文字主区域：x 6—52%
信号红产品平面：x 58—100%
接入环：优先锚定恒温阀体或控制核心
```

Scene 08 末帧中的花洒剪影和 Scene 09 的真实渲染必须放在同一个 `ProductStage` wrapper 中。

### 4.3 产品内部锚点

最终产品图交付时需要同时提供归一化锚点数据：

```text
productCenter    产品整体中心
valveCore        恒温阀体或控制核心
topShower        顶喷中心
handShower       手持花洒中心
railMid          升降杆中段
nozzleDetail     硅胶出水嘴特写锚点
baseConnection   进水或安装连接位置
```

示例：

```json
{
  "productCenter": [0.50, 0.50],
  "valveCore": [0.48, 0.68],
  "topShower": [0.60, 0.10]
}
```

具体数值必须根据最终资产测量，不能在代码中凭感觉硬写。

## 5. P0：进入第 09—16 幕精细分镜前必须具备

### 5.1 产品主渲染

| ID | 资产 | 规格 | 主要用途 |
|---|---|---|---|
| PRD-H1-SIL | 中性产品剪影 | 与 H1 主图同画布、同坐标；透明 PNG 或遮罩 | Scene 08 → 09 连续替换 |
| PRD-H1-WARM | 暖光主渲染 | 透明背景；主文件高度建议 3600px 以上 | Scene 09—15 主产品 |
| PRD-H1-NEUTRAL | 中性技术渲染 | 同机位、低情绪光、结构清楚 | Scene 10—11 技术解释 |
| PRD-H1-RED | 暗色红光渲染 | 与暖光版像素级注册一致 | Scene 15 → 16 安全转折 |
| PRD-H1-SHADOW | 独立接触阴影 | 透明背景，不与产品合并 | 产品落地感与场景切换 |
| PRD-H1-MATTE | 产品整体遮罩 | 黑白或 alpha matte | 文字穿越、前后遮挡、局部调色 |

硬性要求：

- `WARM / NEUTRAL / RED / SIL` 画布大小完全一致。
- 产品在画布中的位置完全一致。
- 不允许不同灯光版本重新裁切。
- 不允许产品边缘自带无法去除的背景辉光。
- 原始主文件保留 PNG 或 TIFF；网页运行版本另导出 WebP／AVIF。

### 5.2 拆件与局部层

以最终产品结构为准，建议至少准备：

| ID | 候选部件 | 是否必须独立 | 用途 |
|---|---|---:|---|
| PART-01 | 恒温阀体／主体 | 是 | Scene 10 的功能与材质核心 |
| PART-02 | 恒温阀芯 | 是 | “恒温出水”机制锚点 |
| PART-03 | 不锈钢升降杆 | 是 | 材质与结构锚点 |
| PART-04 | 顶喷 | 是 | 出水体验与场景锚点 |
| PART-05 | 手持花洒 | 建议 | 家庭与灵活使用场景 |
| PART-06 | 硅胶出水嘴局部 | 是 | 易清洁、减少堵塞的特写 |
| PART-07 | 软管／连接件 | 可选 | 安装与完整性说明 |
| PART-08 | 安装底座／进水接口 | 可选 | 安装问题与工程场景 |

拆件交付方式二选一：

```text
A. 每个零件独立透明图，全部保持在 H1 主画布坐标内。
B. 提供完整 GLB，同时输出一套已注册的二维拆件回退图。
```

不接受只有一张合成爆炸图，因为那会失去逐件运动和连接线控制能力。

### 5.4 六类业务输出样板

至少提供以下可用于画面排版的真实或经过确认的样板：

2. 一条朋友圈／社交内容。
3. 一张海报标题与副标题。
4. 一段销售跟进话术。

## 6. P1：显著提升产品戏剧性的资产

| 资产 | 推荐规格 | 作用 |
|---|---|---|
| 花洒 GLB 模型 | 压缩后 2—4MB，材质与比例准确 | 可控旋转、局部拆解、光照变化 |
| 3—5 秒流水循环 | 4K 或 1080p 无缝循环，透明或深色背景 | 让产品在讲解状态中保持生命感 |
| 阀芯微距渲染 | 1600px 以上 | Scene 10 技术局部放大 |
| 硅胶出水嘴微距 | 1600px 以上 | 易清洁与防堵表现 |
| 家庭浴室场景 | 16:9，留文字安全区 | 家庭、老人、小孩场景 |
| 酒店客房场景 | 16:9，专业、克制 | 酒店与工程渠道 |
| 安装现场或尺寸图 | 去敏、清晰 | 安装问题与工程可信度 |
| 镀层／材质细节 | 同一色彩管理 | 金属质感和耐用印象 |

P1 不应阻塞第一版分镜，但能够显著提高 Scene 09、10、13 的完成度。

## 9. 参数到客户利益：首版内容映射

以下是基于逐字稿的视觉演示草案，正式使用前必须由企业确认。

| 参数／功能 | 可表达的客户利益 | 典型场景 | 资料状态 |
|---|---|---|---|
| 恒温出水 | 减少水温忽冷忽热，提升淋浴体验 | 家庭、酒店客房 | 待产品机制验证 |
| 防烫设计 | 老人、小孩使用时更安心 | 家庭、养老公寓 | 待确认安全结构与表述 |
| 硅胶出水嘴 | 日常清洁更方便，降低水垢堵塞维护难度 | 酒店、高频使用 | 待确认实际材质 |
| 铜主体 | 提供耐用、稳定和更有质感的产品印象 | 家装、工程渠道 | 待确认具体部位与材质 |
| 不锈钢升降杆 | 结构稳固、适合日常调节 | 家庭、酒店 | 待确认材质与调节范围 |
| 节水设计 | 在满足使用体验的前提下控制用水 | 家庭、工程 | 必须有测试依据，禁止先写百分比 |

视觉表现应清楚区分：

```text
左侧：产品事实
中间：AI 转译过程
右侧：客户能理解的利益
```

AI 的作用是翻译与组织，不是创造不存在的产品能力。

## 10. 业务样板的内容与视觉规格

### 10.1 Scene 11：参数卡与利益卡

参数卡建议每张不超过：

```text
中文 4—8 字
英文或数字 1 行
最多 1 个结构标记
```

利益卡建议每张不超过：

```text
标题 6—12 字
说明 14—24 字
场景标签 1—2 个
```

要求至少完成四组一一映射，不能只做泛化漂亮文案。

### 10.2 Scene 12：销售素材

#### 朋友圈／社交内容

画面只需要展示：

```text
首句钩子
2—3 个利益点
一个咨询动作
```

建议长度 45—80 个汉字，不在大屏展示完整长文。

#### 海报

至少准备：

```text
主标题 1 条
副标题 1 条
产品利益标签 2—3 个
CTA 1 条
```

逐字稿示例方向：

```text
稳定水温
让每一次淋浴更安心
```

#### 销售跟进话术

建议分成两个条件分支：

```text
家庭客户：老人 / 小孩 / 安全感
酒店工程：清洁 / 维护 / 稳定使用
```

Scene 12 的重点是同一客户利益如何进入不同载体，而不是展示大量文案。

### 10.3 Scene 13：45 秒短视频分镜

锁定为 5 段时间结构：

```text
00—05s   痛点钩子
05—15s   恒温控制
15—25s   家庭使用场景
25—35s   易清洁细节
35—45s   产品全貌与咨询动作
```

每段准备：

```text
画面描述
镜头类型
字幕
产品动作
必要素材
```

视频工作台不播放完整 45 秒视频。主屏只展示分镜如何从资料中生成，并允许讲师逐段点亮。

### 10.4 Scene 14：英文询盘

建议使用逐字稿中的酒店项目询盘作为输入：

```text
We are looking for thermostatic shower sets for hotel projects.
Please send product details, main features, MOQ, and warranty information.
```

回复稿必须做到：

- 已知产品事实正常生成。
- 未知 MOQ、质保、价格使用占位符。
- 占位符使用醒目的“人工确认”状态。
- 不使用看似完整但没有依据的商业数字。

### 10.5 Scene 14：FAQ 与异议处理

建议至少准备四问：

```text
水温会不会忽冷忽热？
老人和小孩使用安全吗？
出水嘴会不会堵塞？
安装是否复杂？
```

如要展示“质保多久”，答案只能来自正式政策；否则显示待确认状态。

### 10.6 Scene 15：多部门复用

五条部门轨道：

```text
市场：海报 / 社交内容
销售：卖点 / 跟进话术 / 异议处理
视频：脚本 / 分镜
外贸：英文回复初稿
客服：标准 FAQ
```

每条轨道只保留 1—3 张代表卡，避免形成信息墙。

所有卡片必须能追溯到同一份产品资料包，视觉上使用同一个 `sourceId` 或中心连线。

## 12. Scene 08 → 09 的无缝交接合同

### 12.1 Scene 08 末帧

```text
背景：暖白 + 右侧信号红产品平面
产品：中性剪影
ProductStage：x 62% / y 53%
接入环：位于产品后方，缺口朝向阀体区域
四张准备卡：产品 / 资料 / 场景 / 审核边界
巨型后景文字：真实产品
```

### 12.2 Scene 09 首个 Beat

不让产品从屏幕外飞入。执行：

```text
剪影 opacity 1 → 0
暖光产品 opacity 0 → 1
独立接触阴影 opacity 0 → 1
接入环从产品后方微调到 valveCore 锚点
四张准备卡降低对比度并退到边缘
巨型“真实产品”前景切片显现
```

建议时长：

```text
主体替换：280—420ms
高光扫过：450—650ms
文字遮挡完成：700—1000ms
```

这是“真实产品被照亮”，不是“新图片被加载”。

### 12.3 绝对禁止

- Scene 09 重新创建一个不同尺寸的产品节点。
- 剪影和主图使用不同裁切。
- 产品从下方弹跳进入。
- 暖光产品出现时整屏一起淡入。
- 圆环与产品阀体没有稳定关系。

## 13. Scene 15 → 16 的安全转折合同

Scene 15 最后一次生成完成后：

```text
所有卡片停止运动
环境循环停止
鼠标视差停止
接入环亮度短暂提高
声音模式下可使用一次很轻的低频截止音
```

随后：

```text
暖光产品与暗色红光产品在完全相同坐标交叉切换
背景由暖白通过接入环遮罩进入深色空间
所有输出卡被半透明边界包围
主屏只留下：快，还不够
接入环开始收紧为防护结构
```

暗色红光产品必须与暖光版像素级注册，否则观众会看到产品“跳了一下”，破坏连续镜头。

## 14. 文件格式与生产规格

### 14.1 原始主文件

```text
产品渲染：PNG / TIFF，透明背景，建议 16 bit
遮罩：PNG，灰度或 alpha
矢量：SVG
视频：ProRes / 高码率 H.264 主文件
3D：GLB / Blender 源文件
文字资料：Markdown / JSON / CSV
```

### 14.2 网页运行文件

```text
透明产品：WebP，必要时 PNG 回退
照片：AVIF + WebP
视频：MP4 H.264，必要时 WebM
图标与结构：Inline SVG
数据：JSON / TypeScript
```

### 14.3 分辨率

```text
产品主渲染主文件：高度 3600—4200px 推荐
产品网页运行版：高度 1800—2400px
零件特写：至少 1600px
场景图片：至少 2560 × 1440
海报样板：至少 1600 × 2000
视频分镜图：至少 1280 × 720
```

### 14.4 色彩

- 统一使用 sRGB 网页交付。
- 暖光、技术中性和红光版必须保持产品本色可辨认。
- 不用极端纯黑吞掉金属边缘。
- 暖白背景在投影仪上要保留层次，不使用纯白大面积高亮。

## 23. 本阶段最终结论

第 09—16 幕的高级感不会主要来自“多做几个动画”，而取决于三件事：

1. **同一个产品在多个视觉状态间保持绝对连续。**
2. **所有业务输出都能追溯到同一份真实资料。**
3. **生成速度最终被人工审核和安全边界接住。**

因此，下一步不是立刻编写完整页面，而是先完成两项输入：

```text
A. 填写《花洒产品资料采集表 V1》
B. 选定或制作 H1 主视觉套装
```

两项输入锁定后，再进入《21 幕视觉分镜规格 V1｜第三批 09—16》。
