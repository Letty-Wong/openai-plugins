# Gate B Review Kit Command

Run:

```bash
npm run review:gate-b:kit
```

Purpose:

- print the exact review URLs for SR-04, SR-05, and SR-06;
- list the required forward and backward recording filenames;
- show the human questions that must be answered before Gate B can pass;
- include current Gate B machine status.

This command does not approve Gate B or start SR-07.
