# 21 幕视觉分镜规格 V1

## 第一批：第 01—04 幕「做出判断」

> 状态：视觉规划稿，可用于静态关键视觉与动效原型；暂不进入完整页面编码。

---

## 1. 本批任务

第 01—04 幕覆盖课程的开场与“窗口期判断”，承担四个任务：

1. 在第一眼建立高级、可信、面向企业经营者的视觉气质。
2. 明确这不是工具教学或概念科普，而是一项经营判断。
3. 用一条连续轨道解释：电商、短视频、直播、跨境与 AI 都在重排企业效率。
4. 将“现在低成本验证”与“以后系统补课”可视化，并自然进入第 05 幕“四本账”。

本批不出现花洒产品，不使用写实人物或工厂照片。唯一持续主角是 **AI 接入环**。

---

## 2. 重要结构修正：Scene + Beat

21 幕是叙事场景，不等同于 21 次按键。

前四幕承载约 20 分钟讲解，需要在同一场景内分步释放信息。因此采用两级状态：

```text
Scene：完整的视觉空间与主题
Beat：场景内由讲师手动推进的局部信息与动作
```

控制原则：

```text
右方向键 / Space：推进一个 Beat；当前幕最后一个 Beat 后进入下一幕
左方向键：回退一个 Beat；当前幕首个 Beat 前返回上一幕
Shift + 左右方向键：直接切换 Scene
数字键：章节跳转
R：重置当前 Scene 到第一个 Beat
```

所有 Beat 必须可逆，不使用依赖播放时间的不可恢复动画。

---

## 3. 第一章全局视觉规格

### 3.1 舞台比例

以 1920 × 1080 为设计基准：

```text
安全区左右：96px
安全区上下：72px
标题最大视觉宽度：1728px
关键信息最低字号：36px
投影关键线条最低宽度：2px
```

浏览器允许裁切装饰元素，但标题、问题、进度与演讲提示不得进入危险区。

### 3.2 色彩

```css
--void: #08090B;          /* 主背景，避免投影时纯黑丢失层次 */
--void-raised: #111318;   /* 轨道、卡片、层级 */
--ivory: #F1EEE6;         /* 主要文字与暖白平面 */
--signal: #E63A2E;        /* 接入状态、重点和路径 */
--signal-hot: #FF584A;    /* 仅用于短暂高亮 */
--metal: #8D9299;         /* 未激活结构 */
--muted: #626770;         /* 次要路径 */
--line: rgba(241,238,230,.18);
```

禁止大面积霓虹渐变、彩虹色、蓝紫 AI 科技风。第一章只有黑、暖白、信号红和金属灰。

### 3.3 字体角色

- 中文展示字：极粗、紧凑的现代黑体，建议先以 Noto Sans SC / Source Han Sans SC Heavy 验证。
- 英文与数字：窄体无衬线，用于 `01 / 06`、`WINDOW`、`DECISION` 等结构标签。
- 正文与辅助句：中性黑体 Regular / Medium。

文字本身是构图元素，不使用大量正文卡片。

### 3.4 AI 接入环

接入环由 5 个分段组成，预留一个明显缺口：

```text
5 个分段：代表趋势判断、产品生成、场景诊断、安全边界、落地陪跑
缺口：代表企业尚未接入的第一个真实业务场景
```

第一章不显示五段的语义标签，只让它以抽象结构存在。

建议几何：

```text
外径：820px（Scene 01 基准）
主线宽：14px
内侧高亮线：2px
分段间隙：8°
主缺口：38°—44°
缺口默认方向：右下约 4:30 方向
```

环需要拆成：

```text
ring-base       金属暗环
ring-active     红色激活段
ring-edge       细暖白边
ring-glow       非必要低强度辉光
ring-marker     缺口旁的状态点
```

### 3.5 固定图层

```text
L0  BackgroundSystem      背景、暗部渐变
L1  TextureLayer          微弱颗粒和网格
L2  RailSystem            时间线、分支路径
L3  TypographyBack        后景巨型文字
L4  IntegrationRingBack   接入环后层
L5  MainObjects           轨道节点、企业标记
L6  IntegrationRingFront  接入环前景片段
L7  TypographyFront       前景文字切片
L8  StructuralUI          章节、进度、来源提示
L9  PresenterHUD          仅讲师可见
```

### 3.6 动效节奏

每个 Beat：

```text
进入时间：0.75—1.2s
稳定时间：无限，由讲师决定
主要缓动：power4.inOut
局部揭示：power3.out
机械停靠：expo.out，但避免明显回弹
```

第一章不使用弹簧、弹跳和随机漂浮。

环境循环：

```text
接入环角度呼吸：±0.7°
状态点亮度：0.7 → 1
深层颗粒位移：2—4px
周期：4—6s
```

# Scene 01 — AI 效率红利

## 1. 叙事目的

建立整场课程的第一印象：

- 这是一场企业经营判断，不是互联网产品发布会。
- AI 的意义不是“新奇”，而是效率差距。
- 接入环首次出现，并成为后续所有场景的持续视觉主角。

## 2. 屏幕文案

主屏第一状态：

```text
AI
效率
红利
```

辅助句：

```text
从第一个真实业务场景接入
```

最后一个 Beat 才出现：

```text
现在，要不要接入？
```

屏幕上不出现完整课程副标题和长介绍。讲师、主办方、日期可以在左上角以小型结构信息显示。

## 3. 构图

基准坐标采用视口百分比：

```text
接入环中心：x 62 / y 51
接入环直径：约 43vw，最大 820px
“效率”后景：x 5 / y 17，字号约 270px
“红利”前景：x 57 / y 65，字号约 190px
“AI”结构标：x 5 / y 9，字号约 64px
辅助句：x 6 / y 86
章节标识：右上角 01 / 06  判断
```

“效率”部分被接入环遮挡，“红利”局部压在接入环前方，建立前后空间。

## 4. 图层结构

```text
背景暗部
微弱颗粒
后景“效率”
接入环后半部分
环内暗色雾面
接入环状态点
前景“红利”文字切片
AI 与结构信息
```

标题需要复制前后两层，通过 `clip-path` 控制局部前置，而不是简单设置统一 z-index。

## 5. 起始帧

```text
近黑画面
右下偏中的一个红色状态点
只有极弱环形轮廓
标题不可见
```

不从全白闪入，不使用故障、代码雨或粒子爆炸。

## 6. Beat 设计

### Beat 01.1 — 点亮入口

讲师触发：开场问候结束，准备说明课程边界。

运动：

```text
红色状态点亮起
五段环从状态点两侧被描绘出来
暖白细边比红色主线晚 120ms 出现
背景颗粒轻微被环推开
```

主运动：接入环成形。

辅助运动：左上角结构信息淡入。

### Beat 01.2 — 标题进入空间

讲师触发：说出课程主题或“AI 效率红利”。

运动：

```text
“效率”从下方遮罩上移 80px
“红利”从环后穿到环前
AI 标识由小放大至最终尺寸
辅助句延后 180ms 出现
```

主运动：标题与环形成遮挡。

辅助运动：环顺时针转动约 5°，缺口移动至右下。

### Beat 01.3 — 抛出经营问题

讲师触发：“今天我们只判断一件事。”

运动：

```text
“效率 / 红利”对比度降低至 35%
环缩小至约 520px，并移到屏幕中心
环内出现“现在，要不要接入？”
缺口状态点短暂增强亮度
```

结束后稳定 2—3 分钟均可，不发生大幅动画。

## 7. 结束帧

```text
接入环居中
问题位于环内
“效率红利”成为周围的低对比背景结构
缺口朝向正下偏右
```

此状态必须无缝进入 Scene 02。

## 8. 与下一幕的连续关系

Scene 02 不重新创建接入环。

进入下一幕时：

```text
接入环维持中心坐标
问题文字沿 Z 轴后退并变暗
左右两侧的“工具 / 概念”文字墙进入
```

## 9. 所需素材

P0：

- 五分段接入环 SVG。
- 颗粒纹理，可代码生成或 256px 无缝透明 WebP。
- 最终字体文件或字体选型。
- 主办方 / 讲师信息。

不需要图片、视频或 WebGL。

## 10. 讲师控制点

```text
01.1 开场问候结束
01.2 说出课程主题
01.3 “今天我们只判断一件事”
```

## 11. 减少动态版本

- 环直接以 220ms 淡入。
- 标题直接显示最终遮挡状态。
- 环不旋转，不做描边动画。
- Beat 01.3 仅替换环内文字。

## 12. Codex 实现提示

- 接入环使用 inline SVG，保证分段可单独控制。
- 标题前后层使用同一文案和同一字号，避免基线错位。
- 动画状态由 Scene/Beat 数据驱动，不在组件内根据点击次数写分支。
- 不引入 Three.js。
- 颗粒必须可关闭，不能影响低性能设备。

## 13. 验收标准

- 静止截图单独看也具备完整构图。
- “效率”“红利”和接入环至少形成两层遮挡。
- 1920×1080 投影上，环的暗段仍可见。
- 问题出现时视觉焦点只有一个。
- 后退 Beat 时标题和环恢复无误。

# Scene 02 — 不是工具课，不是概念课

## 1. 叙事目的

排除观众对课程的两种错误预期：

```text
学工具
听概念
```

最终只留下：

```text
做经营判断
```

这里不是信息解释页，而是一次“清场”。

## 2. 屏幕文案

Beat 初始：

```text
工具
概念
```

极小辅助标签：

```text
不是工具清单
不是未来想象
```

最终状态：

```text
经营判断
```

环内问题：

```text
现在，要不要低成本接入？
```

## 3. 构图

接入环始终位于中心。

两面文字墙：

```text
左墙“工具”：占屏宽约 44%，从左前方进入
右墙“概念”：占屏宽约 44%，从右后方进入
墙体使用暖白文字与暗色平面，不做真实三维模型
```

文字墙通过 CSS 透视形成空间，不使用重型 3D。

## 4. 图层结构

```text
背景
远景概念墙
接入环后层
工具墙
接入环前层
中心判断文字
结构 UI
```

左右墙的前后关系要错开，避免完全对称的普通分屏。

## 5. 起始帧

继承 Scene 01 结束帧：

```text
接入环居中
环内“现在，要不要接入？”
周围标题低对比
```

## 6. Beat 设计

### Beat 02.1 — 工具墙进入

讲师触发：“今天不是 AI 工具课。”

运动：

```text
“工具”从左侧以透视平面进入
它短暂遮挡接入环约 35%
环的前景片段仍压在文字墙上方
左下出现小标签“注册 / 插件 / 提示词”，随后降低对比度
```

主运动：工具墙通过视口。

辅助运动：环向右偏移 3vw，像在给墙让路。

### Beat 02.2 — 概念墙进入

讲师触发：“今天也不是 AI 概念课。”

运动：

```text
工具墙继续向左后方退出
“概念”从右后方进入，并向观众方向移动
“未来 / 模型 / 趋势”三个小词出现后被切掉
环回到正中
```

主运动：两面文字墙交错通过。

辅助运动：背景纵向光线被墙体切割。

### Beat 02.3 — 清场，只留判断

讲师触发：“如果听完只觉得 AI 很厉害，但不知道第一步做什么，就没有价值。”

运动：

```text
工具墙和概念墙从画面上下两个方向离开
所有小标签清除
接入环内只留下“经营判断”
环外下方显示“现在，要不要低成本接入？”
```

“经营判断”不做逐字动画，作为一个完整块快速停靠。

### Beat 02.4 — 两个带走的判断

讲师触发：“听完今天，至少带走两个判断。”

在环的左右出现两个极简锚点：

```text
为什么是现在
从哪里开始
```

两点通过一条未闭合弧线连接，为 Scene 03 的时间轨道做准备。

## 7. 结束帧

```text
中心：经营判断
左锚点：为什么是现在
右锚点：从哪里开始
接入环稍微倾斜约 12°
```

## 8. 与下一幕的连续关系

进入 Scene 03：

```text
两侧锚点沿圆弧远离
接入环 rotateX 至约 68°
圆环在透视中变成椭圆轨道
左右锚点成为时间轨道的起点与终点
```

这不是整屏切换，而是同一个环被重新解释为时间轨道。

## 9. 所需素材

- 无额外外部素材。
- 工具、概念文字墙由 DOM/CSS 构成。
- 可选：非常轻的纵向磨砂纹理。

## 10. 讲师控制点

```text
02.1 “今天不是 AI 工具课”
02.2 “今天也不是 AI 概念课”
02.3 “今天我们只判断一件事”之前的清场
02.4 “至少带走两个判断”
```

## 11. 减少动态版本

- 工具与概念改为左右静态大字。
- 每次 Beat 只改变不透明度和轻微位置。
- Scene 03 前直接切换为平面时间线，不做 3D 倾斜。

## 12. Codex 实现提示

- 文字墙使用 `transform: perspective(...) rotateY(...) translate3d(...)`。
- 不需要创建 WebGL 平面。
- 文字墙离场后设为 `visibility: hidden`，避免持续占据合成层。
- 环的几何状态与标题墙状态分离。

## 13. 验收标准

- “工具”和“概念”都曾明显占据屏幕，但最终完全退场。
- 接入环全程持续存在，没有闪烁或重建。
- 最终画面只剩一个主要判断，不像四项课程目录。
- 反向播放时两面墙按原路径准确返回。

# Scene 03 — 每一轮浪潮，都在重排效率

## 1. 叙事目的

把电商、短视频、直播、跨境与 AI 连接成一条历史逻辑：

> 变化的不是某个工具，而是客户习惯、获客方式、表达方式与团队效率。

这一幕不能做成普通时间轴或五个图标并排，而要像沿着同一条轨道移动。

## 2. 屏幕文案

场景总标题：

```text
每一轮浪潮
都在重排效率
```

轨道节点：

```text
电商
短视频
直播
跨境
AI
```

AI 节点结束后出现：

```text
先被拉开的，是人效差距
```

辅助结构词：

```text
客户习惯 / 获客方式 / 表达速度 / 经验复用
```

## 3. 构图

Scene 02 的接入环倾斜并扩展成一条透视椭圆轨道：

```text
轨道中心：x 50 / y 55
轨道宽度：约 76vw
轨道高度：约 34vh
整体旋转：-5°
当前节点：始终停靠在 x 50 / y 48 附近
历史节点：向左后方缩小
未来节点：位于右前方暗部
```

观众看到的是轨道在移动，而不是镜头不断切换页面。

## 4. 节点视觉

不使用平台品牌 Logo，以抽象业务形态表达：

```text
电商：多个商品窗口组成的网格
短视频：竖向 9:16 内容框
直播：中心点向外扩散的实时波纹
跨境：跨越两个坐标点的长弧线
AI：五分段接入环与资料节点
```

每个节点都使用同一套卡槽尺寸，避免变成五套插画风格。

## 5. 起始帧

继承 Scene 02：

```text
接入环略微倾斜
左右两个判断锚点位于环外
```

进入时环压扁为椭圆，轨道两侧线条延伸，标题从左上遮罩出现。

## 6. Beat 设计

### Beat 03.1 — 电商

讲师触发：提到“电商起来的时候”。

运动：

```text
轨道向左移动
电商节点停靠中央
节点内部商品窗口依次亮起
左下出现“渠道结构改变”
```

稳定后商品窗口只做极轻的深浅变化。

### Beat 03.2 — 短视频

讲师触发：提到“短视频起来的时候”。

运动：

```text
电商节点沿轨道退向左后方
短视频竖屏框进入中央
竖屏中三层裁切框快速对齐
辅助词切换为“第一眼从内容开始”
```

不播放真实视频，避免抢夺讲师注意力。

### Beat 03.3 — 直播

讲师触发：提到直播。

运动：

```text
竖屏框压缩为中心点
点向外扩散两圈波纹，形成直播节点
轨道亮度短暂提升
辅助词切换为“展示与信任改变”
```

### Beat 03.4 — 跨境

讲师触发：提到跨境平台与海外客户获取。

运动：

```text
直播波纹的一段被拉长为跨越轨道的弧线
两个远端坐标点亮起
节点停靠中央
辅助词切换为“询盘与响应改变”
```

### Beat 03.5 — AI

讲师触发：“今天 AI 也是一样。”

运动：

```text
跨境弧线收回接入环缺口
五分段环重新立起约 28°
多个资料点、内容点和人员点被吸引到环周围
AI 节点变成整条轨道最亮节点
```

主标题中的“重排效率”提高对比度。

### Beat 03.6 — 改变的不是工具

讲师触发：“真正的变化不是工具本身。”

运动：

```text
五个历史节点同时降低对比度
四个结构词围绕 AI 节点出现：
客户习惯 / 获客方式 / 表达速度 / 经验复用
轨道背景向外扩张，形成业务系统感
```

### Beat 03.7 — 人效差距

讲师触发：“AI 会先拉开企业之间的人效差距。”

运动：

```text
AI 节点左侧生成两个完全相同的企业标记
两个标记同时进入下一段轨道
一个标记连接资料、模板与审核节点，变为红色路径
另一个维持灰色，路径速度较慢
标题替换为“先被拉开的，是人效差距”
```

这里建立 Scene 04 的两条路径，不能在下一幕重新创建。

## 7. 结束帧

```text
屏幕左侧：历史节点逐渐退远
中央偏右：红、灰两个企业标记并行
两条路径刚开始分离
底部：先被拉开的，是人效差距
```

## 8. 与下一幕的连续关系

进入 Scene 04：

```text
历史轨道退到背景
红灰两条路径扩大，成为主构图
摄像机视觉重心从时间节点转向两家企业的路径
```

路径起点和企业标记必须是同一 DOM/SVG 对象。

## 9. 所需素材

全部可用代码与 SVG 生成：

- 五类抽象节点组件。
- 透视椭圆轨道 SVG。
- 两个企业标记。
- 四个结构词标签。

不使用品牌 Logo、股票图、新闻截图或人物照片。

## 10. 讲师控制点

```text
03.1 电商
03.2 短视频
03.3 直播
03.4 跨境
03.5 “今天 AI 也是一样”
03.6 “真正的变化不是工具本身”
03.7 “先拉开的是人效差距”
```

## 11. 减少动态版本

- 改为横向时间轨道。
- 节点不沿透视移动，只切换激活状态。
- 03.7 直接显示红灰两条静态路径。
- 取消所有 rotateX、缩放景深和波纹扩散。

## 12. Codex 实现提示

- 每个节点是同一组件的不同 `variant`。
- 轨道通过 wrapper 的 `translateX / scale / rotate` 驱动，不移动大量子节点。
- 五个 Beat 的目标位置写成状态表，不进行相对位移累加。
- 圆环转轨道可用双结构交叉配合 transform，不依赖付费路径变形插件。
- 每次 Beat 完成后清除不再需要的 `will-change`。

## 13. 验收标准

- 五个阶段看起来属于同一条轨道，而非五张轮播图。
- 历史节点保留上下文，但不会与当前节点争夺焦点。
- AI 节点出现时没有俗套代码雨或机器人头像。
- 03.7 的两个企业标记完全相同，差距来自后续系统，而不是初始大小不同。
- 快速前进到 03.7 或反向返回 03.1 时状态无残留。

# Scene 04 — 现在是红利，以后是补课

## 1. 叙事目的

将“窗口期”从口号变成可见的经营路径：

```text
现在：用一个小场景低成本验证
以后：补资料、补流程、补认知、补样板、补效率差距
```

视觉语气必须有压力但不制造恐慌。红色路径不是突然爆发，灰色路径也不是坠落；差距通过持续的小幅积累拉开。

## 2. 屏幕文案

主判断：

```text
现在入场是红利
观望以后是补课
```

两条路径标签：

```text
低成本验证
继续观望
```

补课节点：

```text
补资料
补流程
补认知
补样板
补差距
```

稳定辅助句：

```text
差距不是突然出现，而是每天一点点累积
```

## 3. 构图

两条路径从同一点出发，向右展开：

```text
共同起点：x 13 / y 53
红色路径终点：x 82 / y 34
灰色路径终点：x 82 / y 70
红色路径为缓慢向上的弧线
灰色路径先保持水平，后段经过五个补课节点
```

右侧终点放置一个未激活的圆形经营仪表盘，作为第 05 幕的入口。

重要：不是传统左右对半对比，而是同一空间内的两条业务路径。

## 4. 图层结构

```text
历史轨道残影
共同起点
红灰企业标记
两条路径
红色能力模块
灰色补课节点
右侧经营仪表盘
前景主判断文字
结构 UI
```

## 5. 起始帧

继承 Scene 03.7：

```text
两个相同企业标记刚进入不同路径
历史节点退到左后方
```

## 6. Beat 设计

### Beat 04.1 — 分路，但差距尚小

讲师触发：“这件事为什么要现在看？”

运动：

```text
红灰路径分别展开
两个企业标记前进距离几乎相同
红色路径标记“低成本验证”
灰色路径标记“继续观望”
```

强调现在的选择成本差异，而不是胜负。

### Beat 04.2 — 一个小场景先跑

讲师触发：“先拿一个产品、一个岗位、一个场景去跑。”

运动：

```text
红色企业标记经过一个小型验证门
门后生成四个小模块：资料 / 模板 / 审核 / 样板
模块依次吸附到红色路径周围
路径只领先约 8%—10%，不夸张
```

### Beat 04.3 — 补资料

讲师触发：“你要补资料。”

运动：

```text
灰色路径出现第一道窄门“资料”
灰色企业标记短暂停靠
红色路径上的资料模块已处于完成状态
```

### Beat 04.4 — 补流程与认知

讲师触发：“你要补流程，你要补员工认知。”

运动：

```text
灰色路径连续出现“流程”“认知”两个节点
节点不是障碍墙，而是需要完成的结构环
红色企业标记继续匀速前进
红灰距离逐渐扩大
```

### Beat 04.5 — 补样板

讲师触发：“你要补业务样板。”

运动：

```text
灰色路径出现空白样板框
框内没有内容，提示需要重新验证
红色路径已有一个完整小样板卡
```

### Beat 04.6 — 补效率差距

讲师触发：“还要补别人已经形成的效率差距。”

运动：

```text
灰色路径出现最后节点“差距”
它不是一堵墙，而是一段额外的路径长度
红色企业标记已接近右侧经营仪表盘
主判断“现在入场是红利 / 观望以后是补课”完成显现
```

这一 Beat 是本幕情绪最高点，但不使用闪烁、警报或震动。

### Beat 04.7 — 低成本验证，不是全面改造

讲师触发：“窗口期最适合做的，不是一次性大投入，而是低成本验证。”

运动：

```text
所有补课节点降低对比度
红色路径上的四个小模块飞向右侧经营仪表盘
仪表盘形成四个象限轮廓
红、灰两条路径弯曲并汇入仪表盘外环
下一幕的四个象限预亮 20%
```

这是第 04 → 05 幕的关键原型转场。

## 7. 结束帧

```text
右侧：四象限经营仪表盘形成，但无文字
左侧：两条路径保留为暗部来源
中央主句：低成本验证
红色企业标记停靠在仪表盘入口
```

## 8. 与下一幕的连续关系

Scene 05 开始时：

```text
镜头重心推向右侧仪表盘
仪表盘移动至中心并放大
四个象限依次命名为：开源 / 节流 / 提效 / 沉淀
路径与历史残影退出暗部
```

Scene 05 不创建新圆盘，而是复用 Scene 04 的经营仪表盘。

## 9. 所需素材

全部可代码生成：

- 双路径 SVG。
- 企业标记组件。
- 验证门。
- 四个能力模块。
- 五个补课节点。
- 四象限经营仪表盘。

可选资料：官方政策来源卡只作为右下角小型可展开来源，不进入主转场。

## 10. 讲师控制点

```text
04.1 “为什么要现在看”
04.2 “一个产品 / 岗位 / 场景先跑”
04.3 补资料
04.4 补流程、补认知
04.5 补样板
04.6 补效率差距
04.7 “不是一次性大投入，而是低成本验证”
```

## 11. 减少动态版本

- 两条路径直接显示最终布局。
- 各补课节点按 Beat 逐个高亮。
- 不让企业标记沿曲线路径移动。
- 04.7 直接将右侧圆盘提高对比度并显示四象限轮廓。

## 12. Codex 实现提示

- 路径使用 SVG `path`，企业标记可以通过 `getPointAtLength()` 定位。
- 每个 Beat 保存绝对进度值，例如 0.18、0.30、0.44，禁止用“再向前 100px”的累加动画。
- 红灰标记共用同一组件和尺寸。
- 04.7 的四象限圆盘必须成为 Scene 05 继续使用的持久对象。
- 路径标签与节点不可小于 34px，避免投影模糊。

## 13. 验收标准

- 两家企业从完全相同位置和状态出发。
- 差距通过多个小步骤累积，不是突然拉开。
- “补课”表现为需要建设的能力，不表现为企业失败或坠落。
- 04.7 后能清楚看出四象限圆盘的雏形。
- 从 04.7 进入 Scene 05 时没有整屏闪白或淡黑。

## 6. 建议的数据结构

```ts
type BeatSpec = {
  id: string;
  speakerCue: string;
  screenCopy?: {
    headline?: string;
    subline?: string;
    labels?: string[];
  };
  targetState: VisualState;
  transition: {
    duration: number;
    ease: string;
  };
};

type SceneSpec = {
  id: "scene-01" | "scene-02" | "scene-03" | "scene-04";
  chapter: "judgement";
  title: string;
  beats: BeatSpec[];
  reducedMotionState: VisualState;
};
```

第一批持久视觉状态至少包含：

```ts
type VisualState = {
  background: {
    level: number;
    vignette: number;
  };
  ring: {
    x: number;
    y: number;
    scale: number;
    rotateX: number;
    rotateY: number;
    rotateZ: number;
    activeSegment: number;
    gapAngle: number;
    opacity: number;
  };
  typography: Record<string, {
    x: number;
    y: number;
    scale: number;
    opacity: number;
    clip: number;
  }>;
  timeline: {
    progress: number;
    activeNode: number;
    opacity: number;
  };
  paths: {
    redProgress: number;
    grayProgress: number;
    activeCatchupNodes: number;
  };
  ledgerDial: {
    x: number;
    y: number;
    scale: number;
    quadrantReveal: number;
  };
};
```

原则：GSAP 从当前绝对状态过渡到目标绝对状态；组件不依赖历史点击累加位置。
