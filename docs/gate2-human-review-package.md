# WP-35R Gate 2 人工验收材料包

## 目标

本文件用于人工验收 Gate 2 三段关键空间转场。它不是最终美术验收，也不是素材验收。

本轮只判断：

- 是否能看出同一个空间在转向、穿越、后拉。
- 是否能看出同一个演员持续在场，而不是重新换页。
- 前进、后退、快速输入后是否稳定。
- Reduced Motion 是否保留逻辑但减少运动。
- 产品、CTA、业务事实是否继续保持 placeholder。

## 验收前准备

本地运行：

```sh
npm run dev
```

浏览器使用：

```text
http://localhost:3000
```

不要使用 `127.0.0.1:3000` 做人工验收，Next dev 的开发资源可能触发跨源限制。

建议验收尺寸：

- `1366 x 768`
- `1920 x 1080`

建议先保持 presenter HUD 折叠。需要切换 Reduced Motion 时，按 `h` 展开控件，再点 `Motion`。

## 辅助命令

可以在另一个终端运行：

```sh
npm run review:gate2
```

这个命令会从当前代码合同生成中文验收清单，方便复制截图 URL、核对三段转场和素材 gate。它不自动截图、不自动录屏，也不替代人工验收结论。

验收结果请记录到：

```text
docs/gate2-evidence-ledger.md
```

这份台账按 `AGENTS.md` 的 Gate 2 要求逐项列出证据，能帮助判断是否允许进入下一工作包。

## 无剪辑录屏脚本

录屏必须从开始到结束连续，不中途剪切。

### 录屏 A：Scene 08 到 09 横向产品转弯

起点：

```text
http://localhost:3000#scene-08/08.7
```

操作：

1. 停留 2 秒，让观众看见产品已经在场。
2. 按一次右方向键，进入 `09.1`。
3. 停留 3 秒，观察 `turn-horizontal-product` 灰盒。
4. 按一次左方向键，回到 `08.7`。
5. 再按一次右方向键，回到 `09.1`。

必须看见：

- 不是整页 fade。
- `IntegrationRing` 和 `ProductStage` 不是重新换身体。
- 运动感是从纵向经营路线转入横向产品段。
- 产品仍是 `shower-h1-placeholder`，没有伪装真实产品图。

### 录屏 B：Scene 15 到 16 Z 轴向前穿越

起点：

```text
http://localhost:3000#scene-15/15.8
```

操作：

1. 停留 2 秒，让观众看见输出冻结状态。
2. 按一次右方向键，进入 `16.1`。
3. 停留 3 秒，观察 `portal-forward-safety` 灰盒。
4. 按一次左方向键，回到 `15.8`。
5. 再按一次右方向键，回到 `16.1`。

必须看见：

- 转场是向前穿过接入环进入安全空间。
- `ProductStage` 仍在场，不重新 reveal。
- `SafetyBoundary` 成为安全空间主角。
- 没有使用红光/真实素材伪装安全转折。

### 录屏 C：Scene 20 到 21 Z 轴后拉揭示

起点：

```text
http://localhost:3000#scene-20/20.10
```

操作：

1. 停留 2 秒，让观众看见行动路径近景。
2. 按一次右方向键，进入 `21.1`。
3. 停留 3 秒，观察 `dolly-back-finale` 灰盒。
4. 快速执行：右、左、右，最后停在 `21.1`。
5. 停留 3 秒，确认画面没有残留错位。

必须看见：

- 不是普通缩小页面，而是后拉揭示完整闭环。
- `ActionPath` 不重新入场成另一张终幕图。
- CTA 在可见时仍是 placeholder。
- 快速操作后没有残留旧 transform 或旧灰盒变量。

### 录屏 D：Reduced Motion

起点：

```text
http://localhost:3000#scene-15/15.8
```

操作：

1. 按 `h` 展开 presenter HUD。
2. 点击 `Motion`，打开 Reduced Motion。
3. 按一次右方向键，进入 `16.1`。
4. 停留 3 秒。

必须看见：

- `16.1` 的空间关系仍成立。
- 转场不做长距离运动。
- Gate 2 灰盒直接处于稳定终态。

## 通过标准

Gate 2 可以通过人工验收，当且仅当以下全部成立：

- 三段转场方向能被非工程读者说出来：横向转弯、向前穿越、向后拉远。
- 观众能感到这是同一舞台，而不是三张新 PPT。
- `IntegrationRing` 在三段里像同一个连续演员。
- `ProductStage` 从产品段到安全段再到终幕保持同一占位产品身份。
- `ActionPath` 在 Scene 20 到 21 不下场重进。
- 前进、后退、快速输入后画面没有残留旧位移、旧缩放或旧灰盒变量。
- Reduced Motion 保留空间逻辑，但明显减少运动。
- 主屏不显示工程提示、真实二维码、假产品图或未经确认业务事实。
- 旧 page-chain 视觉没有重新挂回主舞台。

## 不通过标准

出现任一情况即不通过：

- 看起来仍像左右翻页或整页 fade。
- 同一演员在连续 Beat 中明显反复入场。
- 产品或行动路径像换成了另一套身体。
- `09.1`、`16.1`、`21.1` 三段方向无法区分。
- 快速操作后画面错位、残留旧 transform、出现重复层。
- Reduced Motion 打开后仍播放长距离运动。
- 出现真实二维码、假产品素材、假 MOQ / 价格 / 认证 / 交期 / 名额 / 日期。

## 验收后决策

人工验收只给三种结论：

| 结论 | 后续动作 |
| --- | --- |
| 通过 | 进入 Scene 01-08 纵向连续灰盒或横向产品段更完整灰盒。 |
| 小修后通过 | 只修 Gate 2 的灰盒方向、遮挡、节奏或清晰度。 |
| 不通过 | 不进入视觉精修，回到演员身份、camera pose、空间路线重新调整。 |

## 仍然阻塞的内容

以下内容不影响 Gate 2 灰盒验收，但会阻塞最终交付：

- 正式花洒产品素材。
- 产品拆件、遮罩、灯光版本。
- 经确认的产品事实。
- 正式业务输出样板。
- 正式 CTA、短链和二维码。
- 主办方、讲师、时间地点等发布信息。
